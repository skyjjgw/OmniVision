# 硬件设备说明与接线指南

## 1. 文档目的
本文件用于补充当前项目的硬件设备组成、技术参数、接口定义和部署建议，帮助新的开发者或设备集成人员在没有原团队现场说明的情况下理解硬件侧结构。

## 2. 整体硬件架构
本项目硬件侧围绕“边缘端设备盒 + 云端服务 + 志愿者移动端”展开：

- 边缘端主控：Raspberry Pi 5
- 图像采集：MIPI-CSI 摄像头
- 定位感知：GNSS / GPS 模块
- 音频输入：麦克风或麦克风阵列
- 音频输出：双声道扬声器、耳机或骨传导设备
- 供电系统：5V / 5A 便携电源或稳定 DC 供电
- 云端：Linux 服务器
- 志愿者端：Android / iOS 手机

## 3. 核心硬件清单
### 3.1 Raspberry Pi 5
#### 角色
- 盲人端核心主控
- 执行本地视觉推理、音频播报、设备 IO 和网络上报

#### 关键技术参数
- CPU：四核 Arm Cortex-A76，主频 2.4GHz
- 内存：常见配置为 4GB / 8GB LPDDR4X
- 网络：千兆以太网、Wi-Fi、Bluetooth
- 视频与摄像头接口：支持 MIPI-CSI 摄像头链路
- 外设扩展：40-pin GPIO，USB 2.0 / 3.0
- 供电：推荐稳定 5V 输入，建议满足高负载场景

#### 在项目中的作用
- 运行 `apps/blind-client/blind_client_pi5_csi.py`
- 调用本地检测模型与音频矩阵
- 负责把危险提示优先在本地播报

### 3.2 MIPI-CSI 摄像头
#### 角色
- 提供前向图像输入
- 支撑红绿灯、障碍物、斑马线等视觉感知任务

#### 当前项目说明
- 项目资料中以 IMX219 类模块为代表
- 接口类型为 MIPI-CSI
- 相比 USB 摄像头，更适合低延迟边缘推理链路

#### 典型参数说明
- 分辨率：8MP 级别（视实际采购型号）
- 接口：CSI-2
- 连接方式：排线直连 Raspberry Pi 摄像头接口

#### 选型原因
- 降低视频采集延迟
- 降低 USB 总线开销
- 更符合本项目“安全提示优先”的设计目标

### 3.3 GNSS / GPS 模块
#### 角色
- 提供定位坐标
- 支撑导航、轨迹记忆与地图联动

#### 当前项目说明
- 项目展示资料中以 LC76G 类 GNSS 模块为代表
- 常见通信方式为 UART 串口

#### 典型参数说明
- 输出协议：NMEA
- 接口类型：UART TTL
- 供电：以模块实际规格为准，接线时必须确认电平兼容性
- 支持卫星系统：GPS / 北斗 / GLONASS / QZSS 等视模块而定

#### 在代码中的体现
- 盲人端相关串口与定位逻辑位于 `apps/blind-client/blind_client_pi5_csi.py`
- 测试与定位验证代码位于 `apps/blind-client/test_gps_pc.py`

### 3.4 麦克风 / 麦克风阵列
#### 角色
- 采集盲人用户语音指令
- 支撑唤醒词、导航问询与场景描述请求

#### 当前项目说明
- 仓库代码以 ALSA / PyAudio 可识别输入设备为准
- 具体麦克风型号可替换，但需保证系统能识别为稳定音频输入设备

#### 接口建议
- USB 音频输入设备
- 麦克风阵列板卡
- 系统可识别的 ALSA 录音设备

### 3.5 播放设备
#### 角色
- 输出安全提示音、导航语音、云端回复和人工协助通话音频

#### 设备建议
- 双声道扬声器
- 耳机
- 骨传导设备

#### 接口建议
- 3.5mm 音频输出
- USB 声卡 / 音频模组
- 蓝牙输出设备（若系统驱动稳定）

### 3.6 供电系统
#### 角色
- 为树莓派与外围设备提供稳定供电

#### 当前项目说明
- 展示资料中出现 5V / 5A 锂电池方案
- 容量以实际采购型号为准，示例图中为万毫安级便携电源

#### 注意事项
- 电流不足会导致摄像头、音频设备或系统负载不稳定
- 供电异常可能直接引发掉帧、USB 掉线或系统重启

## 4. 硬件接口定义
### 4.1 Raspberry Pi 5 接口映射建议
| 模块 | 推荐接口 | 说明 |
| --- | --- | --- |
| MIPI 摄像头 | CSI 接口 | 使用专用排线连接 |
| GNSS 模块 | UART / GPIO | 需确认 TX/RX 与电平兼容 |
| 麦克风 | USB / ALSA 设备 | 以系统可识别输入设备为准 |
| 扬声器 | 3.5mm / USB 音频 | 以实际播放方案为准 |
| 网络 | Wi-Fi / Ethernet | 云端通信必须稳定 |
| 电源 | 5V 稳定供电 | 建议高负载冗余供电 |

### 4.2 GNSS 串口接线示意
典型 UART 连接关系如下：

- 模块 TX -> 树莓派 RX
- 模块 RX -> 树莓派 TX
- 模块 GND -> 树莓派 GND
- 模块电源 -> 按模块规格接 3.3V 或 5V

注意：接线前必须确认 GNSS 模块的串口电平要求，避免直接错误上电。

### 4.3 音频设备要求
- 麦克风必须能在系统中枚举为可录音设备
- 播放设备必须能被系统识别为默认输出或指定输出设备
- 若使用阵列麦克风，建议固定设备编号并在配置中显式指定

## 5. 部署建议
### 5.1 设备盒结构建议
- 树莓派主板固定于盒体中部
- MIPI 摄像头朝前固定
- 麦克风靠近用户头部或胸前朝向
- GNSS 模块尽量避免被金属外壳完全遮挡
- 供电模块与主板分离布线，减少干扰

### 5.2 线材建议
- 摄像头排线避免弯折过度
- 串口线尽量固定，避免松动导致 GPS 数据中断
- 音频线与供电线分开整理，降低噪声影响

## 6. 高风险问题
- 使用 USB 摄像头替代 MIPI 摄像头，会影响端侧时延与稳定性
- 供电不足会导致 Pi 5 高频降频、外设掉线或推理性能下降
- 麦克风设备编号变化会导致 ASR 启动失败
- GNSS 模块接线错误会导致定位长期为空
